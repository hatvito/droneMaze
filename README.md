# Drone Maze Competition Lab (無人機迷宮尋跡大賽教學平台)

本專案融合了**「單機演算法演練 (含挖空任務版)」**與**「跨演算法同場競技 (Benchmark 評測)」**，並支援**「已知終點全圖導航」**與**「戰爭迷霧 (Fog of War) 未知終點探索」**兩大教學情境。

---

## 目錄結構

```
drone-maze-competition/
├── index.html                   # 尋跡大賽主介面 (Tailwind + CodeMirror + Canvas)
├── css/
│   └── style.css                # 滾動條、自訂網格背景與 CodeMirror 覆寫樣式
├── js/
│   ├── mazeGenerator.js         # 種子偽隨機亂數、DFS 與 Prim 迷宮生成模組
│   ├── droneSimulator.js        # 無人機實體、感測器陣列 (前後左右)、迷霧圖層與渲染
│   ├── templates.js             # 內建演算法範本 (含完整版與【挖空任務版 TODOs】)
│   ├── benchmark.js             # 跨演算法多策略競技排行榜評測引擎
│   └── app.js                   # 介面事件綁定、單步/自動播放排程與主控制器
└── README.md                    # 模組結構說明與課堂教學指引
```

## 學生練習與競賽玩法

1. **單機探索演練 (Single Agent)**：
   * 學生可於右側編輯器即時修改演算法邏輯。
   * 下拉選單提供「Trémaux 特雷莫」、「增量 DFS 記憶探索」、「沿牆搜尋法」、「A*」、「BFS」等預設範本。
   * 另提供 **【任務挖空版】**（搜尋與狀態決策填空），讓學生上機挑戰填補 `TODO`。
2. **多演算法大賽 (Benchmark 排行榜)**：
   * 在相同的隨機地圖種子（Seed）與迷霧條件下，讓學生寫的「自訂策略」與內建經典演算法進行同場 PK。
   * 系統將依據**「是否抵達終點」**、**「開圖探索率 (%)」**、**「移動步數」**與**「運算耗時 (ms)」**自動換算綜合評分並頒發名次獎牌（🥇 冠軍、🥈 亞軍、🥉 季軍）。
