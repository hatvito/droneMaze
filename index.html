迷霧探索與編寫規則說明

一、 遊戲兩種模式 (Game Modes)

  • 已知終點模式：終點座標已知，學生可呼叫 planPath(maze, start, goal) 事前規劃全圖最佳解 (A*, BFS)。
  • 未知終點 (迷霧模式 Fog of War)：終點隱藏於迷霧中，無人機僅能靠機載感測器揭露周圍地圖，需編寫 nextAction(drone) 進行實時探索 (Trémaux, 沿牆法, 增量 DFS)。

二、 機載感測器 API (drone)

// drone 機載介面與感測器
drone.x / drone.y       // 當前網格座標
drone.heading          // 當前朝向 ("NORTH", "EAST", "SOUTH", "WEST")
drone.isWallInFront()  // 前方是否有牆壁 (true / false)
drone.isWallRight()    // 右側是否有牆壁 (true / false)
drone.isWallLeft()     // 左側是否有牆壁 (true / false)
drone.isWallBack()     // 後方是否有牆壁 (true / false)
drone.isGoalFound()    // 是否踏入終點格 (true / false)
drone.memory           // 可自訂的持久化記憶體物件 {}

// 傳回動作指令之一:
return "FORWARD"; // 前進一格
return "LEFT";    // 左轉 90 度
return "RIGHT";   // 右轉 90 度
return "U_TURN";  // 掉頭 180 度
